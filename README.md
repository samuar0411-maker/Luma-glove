Luma Glove

Guante inteligente basado en ESP32-C3 y sensores de flexión para controlar videojuegos mediante los movimientos de la mano.

Tecnologías y componentes:

Hardware:
- ESP32-C3 Super Mini
- 4x Flex Sensor 2.2"
- 4x Resistencias de 10 kΩ
- Protoboard
- Cables Dupont
- Guante de tela
- Cable USB-C

Software:
- Arduino IDE
- HTML5
- CSS3
- JavaScript
- Web Serial API
- Google Chrome (Web Serial API)

  
Estado:
