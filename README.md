Luma Glove

A smart glove based on the ESP32-C3 and flex sensors designed to control video games through hand and finger movements.

Technologies and Components:

Hardware:
- ESP32-C3 Super Mini
- 4× 2.2" Flex Sensors
- 4× 10 kΩ Resistors
- Breadboard
- Dupont Jumper Wires
- Fabric Glove
- USB-C Cable

Software:
- Arduino IDE
- HTML5
- CSS3
- JavaScript
- Web Serial API
- Google Chrome (Web Serial API support)

Project Status:

Pilot Testing
